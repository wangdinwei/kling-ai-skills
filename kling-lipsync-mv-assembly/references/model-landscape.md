# 歌曲 MV 对口型：模型版图与选型

价格随官方调整变动，下单前到控制台核一次；这里只记「量级」与「谁适合什么」。

## 一、选型结论（先看这个）

| 要什么 | 用谁 | 为什么 |
|---|---|---|
| 怼脸唱、且要国内直连不折腾 | **可灵 Avatar**（`/v1/videos/avatar/image2video`）| 一张竖屏大特写 + 一段干声 → 模型自己生成头动/表情/口型/运镜，0.4–0.8 积分/秒。详细配方见 `audio-driven-avatar.md` |
| 近景演唱长镜头（一镜 20s～5min） | **OmniHuman**（音频驱动数字人） | 一张图 + 整首歌 → 一镜到底，专为唱歌/表演训练，口型与表情跟着音频走 |
| 动态画面、多机位、真实运镜 | **Seedance**（1.0 pro / 2.0） | 图生视频榜首，原生一次生成 2–3 个镜头切换，运镜能执行，1080p |
| 已有视频只想改嘴 | **后期换嘴**（Wav2Lip / LatentSync / MuseTalk / LivePortrait） | 保留原画面只重绘嘴部，适合二创、换语种 |
| 坐着说话的口播/带货 | **数字人系统**（HeyGen / 智影 / 硅基） | 口型最精确，但场景单一 |
| 广角、背影、空镜 | **都不做对口型** | 看不见嘴，做了白做 |

**核心判断：不要用「通用视频模型 + 逐段对口型」去覆盖整片。** 那是本类任务最贵又最没效果的组合。

## 二、可灵 v3 lip-sync（本技能的主线，国内直连）

- `POST /v1/videos/lip-sync`，`model_name: kling-v3`
- 输入：`video_id`（非 task_id）+ 音频 base64，音频 ≤10s
- 输出：自带音轨 aac 128k、1264×720、比输入短约 0.075s（掐尾，不压缩）
- 耗时约 170s/段；确定性风控会拦部分素材
- 定位：**短片段、近景、单人正面** 最合适

## 三、Seedance（字节，火山方舟 / BytePlus / 即梦）

| 版本 | 能力 | 量级价（1080p 5s）|
|---|---|---|
| 1.0 pro | T2V + I2V，原生多镜头叙事，1080p，运镜可执行 | ¥3.67（10s ≈ ¥7.34）；720p 5s ≈ ¥1.54 |
| 1.5 pro | **音视频联合生成**（自己生成声音），方言/多语种对白 | 按 token 单价，有声为无声的 2 倍档 |
| 2.0 / 2.5 | 可收 `audio_url`（≤15s，最多 3 段）与参考视频，支持 `generate_audio` | 2.0 1080p 5s ≈ ¥12.4；2.5 更贵 |

**关键坑：Seedance 不是拿你的歌去驱动嘴型。** 1.5 pro 是「它自己生成声音」，官方口径也承认歌唱类场景仍待提升。要拿自己的音频驱动，它只能做参考（≤15s），不是专用对口型模型。
→ **画面换 Seedance 是升级；对口型换 Seedance 不是升级。**

## 四、OmniHuman（字节，音频驱动数字人）

| 渠道 | 版本 | 单次时长 | 输出 | 价格 |
|---|---|---|---|---|
| 火山引擎 · 即梦（国内） | 1.5 | 720p <60s；1080p <30s | 720p/1080p | 国内刊例 |
| BytePlus（海外） | 2.0 | **最长 300s 一镜到底** | 720p | **$0.07/秒**（2.0 降价后）|
| 第三方中转 | 1.5 / 2.0 | 同上 | 同上 | $0.105–0.32/秒，普遍更贵 |

国内调用（1.5）是三段流程，`req_key` 分步：

1. 主体识别 `jimeng_realman_avatar_picture_create_role_omni_v15`
2. 主体检测 `jimeng_realman_avatar_object_detection`（拿 mask）
3. 视频生成 `jimeng_realman_avatar_picture_omni_v15`（`image_url` + `audio_url` + `mask_url`）

鉴权走火山 AK/SK（`volcengine` Python SDK 的 `VisualService`），与方舟的 API Key 不是一回事，别混。

**成本量级**：2.0 做完整首 150 秒 ≈ $10.5 ≈ ¥75，比「15 段可灵图生视频 + 19 次对口型」便宜，且没有分段拼接、漂移、风控、二次补口型这些问题——代价是画面只能是一镜到底的单一机位。

## 五、行业内四种做法的取舍

| 路线 | 代表 | 优点 | 代价 |
|---|---|---|---|
| A 专用音频驱动 | OmniHuman / Hedra / Sync.so | 口型最准、可长镜头 | 画面单一，不适合多机位叙事 |
| B 后期换嘴 | Wav2Lip / LatentSync / MuseTalk | 可复用已有成片、便宜 | 只能修嘴，表情/头动不跟 |
| C 数字人口播 | HeyGen / 智影 | 工业级稳定 | 只能是「坐着说」 |
| D 不对口型 | 侧脸/背影/空镜 + 字幕卡点 | 最便宜、最容易出情绪 | 观众看不到口型（但 MV 语境容忍度很高）|

**推荐组合**：D 做大部分镜头（情绪与叙事）+ A 做 2–3 个真正的近景演唱长镜头。这也正是很多爆款 AI 歌的配方——它们并不靠「每个镜头都精准对口型」。

## 六、充值前先看计费形态（比单价更坑）

用户问「几个平台都要充几千，选哪个」时，**先问的不是单价，是这笔钱会不会过期**。

| 计费形态 | 代表 | 对间歇创作的人意味着 |
|---|---|---|
| **预付费资源包 / 灵感值** | 可灵 C 端、各平台会员 | 有有效期，用不完作废；一次充几千 = 赌你一年内能做完十几首 |
| **按量后付费** | 阿里百炼、火山方舟 | 充多少用多少，不做的月份一分不花，没有过期焦虑 |

**可灵 C 端的有效期分层（最易忽）**：充值购买的灵感值 **2 年有效**；会员权益送的灵感值 **只 1 个月**，当月不用就废。别把「送的」当余额算。

**720P 生成单价量级（元/秒，下单前到控制台核一次）**

| 平台 / 模型 | 720P | 备注 |
|---|---|---|
| 阿里百炼 `wan2.2-i2v-flash` | **0.20** | 目前最便宜的可用档，480P 0.10 / 1080P 0.48 |
| 阿里百炼 `wan2.5-i2v` | 0.6 | 1080P 1.0 |
| 火山方舟 Seedance 2.0-fast | 0.6 | 480P 0.35；月累计时长阶梯折扣（≥1 万秒 9 折）|
| 可灵 `kling-v3` std | 0.6 | pro 0.8；无原生音频 |

**建议结构（针对「做一首歌停两个月」的节奏）**：主力放**按量计费的云厂商账户**（图文视频一个 key 跑通、余额不过期）；可灵只留**小额**，专用于两个它做得最好的能力——主体库锁人（`custom-elements`，不计费）与 lip-sync；大额资源包不要碰。

**给用户算账时拿具体一首歌对比**，不要只报单价：157 秒的歌、含重跑约 250 秒生成量 → 可灵约 ¥150，万相 flash 约 ¥50。这种对比才能让「换不换」变成可决策的问题。

## 七、聚合平台（LibTV 这类）：模型更新，但不能自动化

市面上有一批把多家模型打包的工具平台（LibTV、各种「AI 影棚」）。它们常比官方 API 多一代模型（同一个入口能给 Kling 4.0 / Wan 3.0 / Seedance 2.5 / Minimax H3），**但充钱前必须看清三条**。

### 1. 先判断它能不能命令化调用

看它有没有远程 MCP，而不是看它有没有「插件」字样：

```bash
curl -s -i https://<host>/mcp | head -12          # 401 + www-authenticate 就是 MCP
curl -s https://<host>/.well-known/oauth-authorization-server
```

有 `registration_endpoint` 就是标准 MCP，能接进 agent（接入步骤见 `native-mcp` 的 `references/远程MCP的OAuth接入.md`）。

### 2. 但条款常常明确禁止用脚本消耗免费额度

实测这类平台的会员条款原文口径：**「免积分生成权益仅限真人手动使用，不支持 CLI 或其他自动化脚本；疑似机器人或高频使用可能触发暂时停用并接受审核。」**

→ 把「免费额度」接上自动化 = 拿账号赌。**自动化批量生产只能走官方支持程序调用的 API**（可灵开放平台、百炼、火山方舟）；聚合平台留给「手动跑几个关键镜对比质量」。

**汇报时必须把这条说给用户**，不要只报「能接 MCP」——他冲的很可能就是那笔会被封的免费额度。

### 3. 计费形态比单价更坑（与可灵同类问题，但更狠）

| 项 | 实测口径 |
|---|---|
| 会员积分 | **按月发放、31 天有效、未用清零**（月卡年卡都是），不是长期余额 |
| 每日赠送 | 当天有效，次日清零 |
| 退款 | 会员与积分是虚拟商品，**原则上不退** |
| 个人 vs 团队版 | 个人版额度绑账号、不可转让；团队版卖的是**席位 + 共享素材空间 + 三级权限 + 积分池分配**——一个人做片用个人版就够 |

**判据**：如果你不是每月都稳定产出几十个视频，月清零的积分制一定会浪费；按量计费的云账户才是间歇创作的合理选择。

### 4. 但它值得当「质量基准」用

这类平台的「创作精选」里就是行业当前的天花板作品（包括那类百万赞的爆款 AI 歌 MV）。**做法：本机/可灵跑完全片后，把最关键的 2–3 镜用它的最新模型手动跑一遍做对照**——花零钱就知道下一代模型到底强多少，比读参数表可靠。
